# KiCad Project

KiCad 10 projects for the SQMeter main board, in two variants that share everything except the ESP32:

| Project | ESP32 | Who it's for |
|---------|-------|--------------|
| `SQMeter-Hardware.kicad_pro` | ESP32-S3-WROOM-1-N16R8 soldered down, native USB-C on the board edge | JLCPCB fully assembled |
| `SQMeter-Hardware-DevKit.kicad_pro` | ESP32-S3-DevKitC-1 (N16R8) plugged into two 1x22 sockets | Building it yourself without fine-pitch soldering |

Both use the same GPIO map, so they run the same firmware:

| Function | GPIO |
|---|---|
| I2C SDA / SCL | 8 / 9 |
| GPS RX / TX | 18 / 17 |
| RG-15 RX / TX | 16 / 15 |
| Wind speed / vane (ADC1) | 5 / 4 |
| AUX | 6, 7, 10, 11 |
| Status LED (module board only) | 47 |

The DevKit variant feeds the DevKit's 5V pin from a 5 V buck through a Schottky and takes 3V3 back from
the DevKit's LDO for the sensors. The DevKit's own USB ports are diode-isolated, so USB and 12 V can be
connected at the same time.

All four I2C ports share one JST-XH pinout: **1 GND, 2 3V3, 3 SDA, 4 SCL**.

## Files

Generated by `../generator/build.sh <module|devkit>` (see its README); hand-tune in KiCad afterwards.
JLCPCB files (gerber zip, BOM, CPL) come from `../generator/export_jlc.sh <module|devkit>` and land in
`../manufacturing/<project>/`.

Open the `.kicad_pro`, not the `.kicad_sch`/`.kicad_pcb` directly, so library associations resolve.
