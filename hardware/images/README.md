# Images

Board render and preview images for use in documentation and the README.

| File | Description |
|------|-------------|
| `schematic-preview.png` | Schematic preview (for README/docs cards) |
| `pcb-preview.png` | PCB top view render |
| `board-render.png` | 3D board render |

Images are generated artifacts — do not edit by hand. Regenerate via `scripts/export-kicad.sh`.

These files are not yet present — they will be generated once the KiCad project files are committed.
