# BOM

Bill of materials generated from the KiCad schematic. Do not edit these files by hand.

Regenerate:

```bash
./scripts/generate-bom.sh
```

## Expected files

| File | Description |
|------|-------------|
| `bom.csv` | Machine-readable BOM — included in hardware releases |
| `bom.md` | Human-readable Markdown table |
| `bom.html` | Human-readable HTML (optional) |

See `docs/bom.md` for sourcing notes and BOM strategy.
