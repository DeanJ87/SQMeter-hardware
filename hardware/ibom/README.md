# InteractiveHtmlBom

`ibom.html` is a self-contained HTML file for assembly reference. Open it in any browser — no server required.

Regenerate:

```bash
./scripts/generate-ibom.sh
```

Requires [InteractiveHtmlBom](https://github.com/openscopeproject/InteractiveHtmlBom) to be installed.

`ibom.html` is not yet present — it will be generated once the KiCad PCB layout is committed.
