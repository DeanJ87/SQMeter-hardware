# Security Policy

## Scope

This repository contains open hardware design files. Security reports related to the SQMeter firmware or web interface should be directed to the [main SQMeter repo](https://github.com/DeanJ87/SQMeter/security).

Hardware-relevant security concerns (e.g. hardware supply chain issues, dangerous component substitutions, incorrect voltage/isolation warnings) can be reported here.

## Reporting

Please do not open a public issue for security concerns.
